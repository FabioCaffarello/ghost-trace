# Assertion Engine

## Constitutional Role

Derives Category II (operational constructs) and Category III (hypothetical) assertions from observations and enrichment. Every assertion produced here carries observational provenance and, when applicable, inferential influence disclosure.

## Status

Not implemented.

## Required Properties

- Per [Invariant 2.2 — Epistemic Separation](../../docs/charter/constitutional-charter.md#22-epistemic-separation): assertions are produced into typed categories; no unified output type.
- Per [Invariant 2.3 — Provenance Integrity](../../docs/charter/constitutional-charter.md#23-provenance-integrity) (frozen v0.4): every produced assertion carries observational provenance.
- Per [Invariant 2.4 — Inferential Influence Disclosure](../../docs/charter/constitutional-charter.md#24-inferential-influence-disclosure) (frozen v0.5): assertions formed under influence of promoted hypotheses carry influence disclosure.
- Per [Invariant 2.6 — Evidential Independence Integrity](../../docs/charter/constitutional-charter.md#26-evidential-independence-integrity) (frozen v0.6): inferential assertions carry both confidence and independence.
- Versioned computation: the version of the derivation logic is part of every assertion's identity.

# Assertion Engine

## Constitutional Role

Derives Category II (operational constructs) and Category III (hypothetical) assertions from observations and enrichment. Every assertion produced here carries observational provenance and, when applicable, inferential influence disclosure.

## Status

Not implemented.

## Required Properties

- Per [Invariant 2.2 — Epistemic Separation](../../docs/charter/constitutional-charter.md#22-epistemic-separation): assertions are produced into typed categories; no unified output type.
- Per Invariant 2.3 (pending): every produced assertion carries observational provenance.
- Per Invariant 2.4 (pending): assertions formed under influence of promoted hypotheses carry influence disclosure.
- Per Invariant 2.6 (pending): inferential assertions carry both confidence and independence.
- Versioned computation: the version of the derivation logic is part of every assertion's identity.

# Tooling

Versions are pinned in the `Makefile` and asserted by `make bootstrap`.
`.tool-versions` mirrors them for asdf/mise users.

| tool | why it is pinned |
| --- | --- |
| Go (toolchain go1.26.5) | the security floor; govulncheck found five reachable stdlib advisories below it |
| buf 1.68.4 exactly | it decides the generated bytes `genproto-sync` compares |
| protoc-gen-go v1.36.0 | same reason |
| golangci-lint v2.12.2 | a linter that changes underneath you turns a clean tree red on an unrelated PR |
| vacuum | curated OpenAPI ruleset (`.vacuum.yaml`) |

## Two traps this repository has already fallen into

- **`.SHELLFLAGS` needs GNU Make 3.82**; macOS ships 3.81 and ignores it
  silently. Every loop in the Makefile ends in an explicit `|| exit 1`
  rather than relying on `set -e`.
- **No sync gate may use `git status`.** Git reports a file as changed
  relative to HEAD, which is not the question a drift check asks. All
  three sync gates generate to a temporary directory and diff.

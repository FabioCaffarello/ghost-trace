# Experiments

This directory contains time-bounded experiments whose outcomes inform RFCs.

## Status

No experiments are currently active.

## Experiment Discipline

Experiments are governed by RFCs of type `experiment`. Each experiment must declare:

- Its hypothesis.
- Its success criteria.
- Its time bound.
- The decision it informs.

Experiments do not bypass constitutional review. An experiment that demonstrates technical feasibility but violates constitutional invariants is not eligible for promotion to production.

# RFC Discussion Working Artifacts

Working artifacts produced during the discussion phase of an RFC. Artifacts here are not authoritative; they are evidence-gathering and synthesis to support committee decision at the redaction phase. Preserved as historical record.

The analog of [`docs/charter/in-committee/`](../../charter/in-committee/) for Charter redactions: that directory holds redaction-phase artifacts for pending Charter sections; this directory holds discussion-phase artifacts for RFCs whose status is `discussion`.

Files in this directory are evidence inputs to a future decision. They do not constitute the decision itself. Decisions are recorded in [`docs/charter/decision-log.md`](../../charter/decision-log.md); resolved Ontology positions are recorded in the relevant Ontology document.

# `in-committee/` — Charter committee redaction workbench

This directory holds scratch documents for pending Charter elements during committee redaction. Per [`.claude/skills/constitutional/invariant-redactor/SKILL.md` §2](../../../.claude/skills/constitutional/invariant-redactor/SKILL.md), this directory is created the moment redaction begins (not preemptively); each file inside is a working artifact for one pending element (e.g. `§4-constitutional-design-rule.md`); files here are non-binding drafts and are not to be cited as authoritative; merge into [`../constitutional-charter.md`](../constitutional-charter.md) happens only when the redaction passes the final-merge checklist (`invariant-redactor` §3) and the corresponding amendment has been recorded in [`../amendments.md`](../amendments.md).
